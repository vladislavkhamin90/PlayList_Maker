О проекте

Playlist Maker — это мобильное приложение для поиска музыкальных композиций, создания плейлистов и управления избранными треками. Приложение использует iTunes Search API для поиска музыки и предоставляет возможность сохранения треков в избранное, создания собственных плейлистов и их редактирования.
Основные возможности

    Поиск музыки: Интеграция с iTunes Search API для поиска треков по названию, исполнителю или альбому

    История поиска: Автоматическое сохранение истории поиска с возможностью очистки

    Аудиоплеер: Воспроизведение превью треков (30 секунд) с контролем громкости и прогрессом

    Избранные треки: Добавление и удаление треков в избранное с синхронизацией в базе данных

    Плейлисты:

        Создание и редактирование плейлистов

        Добавление треков в плейлисты

        Просмотр деталей плейлиста

    Настройки темы: Поддержка светлой и темной темы с сохранением настроек

Архитектура

Приложение построено с использованием современных подходов Android-разработки:

    Data Layer: Работа с сетью, базой данных и SharedPreferences

    Domain Layer: Бизнес-логика, Use Cases и интеракторы

    Presentation Layer: ViewModel, LiveData и UI компоненты

Используемые технологии

    Kotlin Coroutines: Для асинхронных операций

    Retrofit: Для сетевых запросов

    Room: Для локального хранения данных

    Koin: Для внедрения зависимостей

    ViewBinding: Для работы с UI компонентами

    Navigation Component: Для навигации между экранами

    LiveData/Flow: Для реактивного программирования
